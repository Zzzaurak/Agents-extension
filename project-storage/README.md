# Python 项目技能

[Python 项目设计](python-project-design/SKILL.md) 适用于日常 Python 应用、API、脚本和数据处理。它保留声明式计算、显式 I/O 和便于审查的业务边界，按项目大小和现有技术栈选择实现。

在 Codex 中可直接引用技能目录中的 `SKILL.md`。也可以从外层仓库根目录安装此技能：

```bash
node bin/agents-extension.js install python-project-design
```

安装后可以用 `$python-project-design` 规划或审查项目。分享时提供整个 `python-project-design/` 目录，其中包含入口、界面元数据和按需读取的参考。
