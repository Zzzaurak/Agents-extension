# React 前端审查清单

按改动范围检查，报告位置、对使用者的影响和最小修正。

- **页面归属** 检查入口能否读出主要业务区域。页面专用组件、hook 和纯计算就近维护，共享模块有实际复用需求。
- **数据与状态** 修改核心状态后，派生展示随之更新。渲染使用订阅，用输入验证纯计算。验证实际涉及的导航参数、等待、空结果、失败和成功状态。
- **接口与身份** 从页面追到调用器、HTTP 方法和路径、公开请求与响应类型。用项目已有契约检查或模拟传输验证序列化、可空字段及错误处理。使用请求类时，验证构造过程只保存输入。
- **样式** 使用项目现有的组件、样式和 token。涉及交互或布局时，检查相关的键盘操作、焦点和页面尺寸。
- **交付** 页面与 API 映射和实际代码一致。运行项目已有的类型检查、lint、测试或构建，按改动范围验证。
