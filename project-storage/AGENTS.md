# 技能维护

- 本目录由外层 Agents Extension 仓库跟踪。使用现有 Git 工作流，验证后只提交本次相关改动。保留已有工作区修改。
- 技能目录应可独立分发，引用使用目录内的相对路径。修改技能时使用可用的 `skill-creator` 工作流，核对入口、参考、界面元数据和 README 导航。
- 指南优先记录能改变实现判断的约定。明确哪些是项目现有契约，哪些是可按规模和技术栈调整的建议。
- 提交前检查实际暂存范围和 `git diff --cached --check`。有本机技能验证器时运行格式校验，更新代码示例时验证示例。新增随安装器分发的资源时核对外层 `package.json` 的文件清单。
