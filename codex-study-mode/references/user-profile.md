## Physics Background

The user has previously studied the standard theoretical physics core:

- Classical mechanics.
- Electrodynamics.
- Thermodynamics and statistical mechanics.
- Quantum mechanics.
- General relativity.

However, the current working assumption is not active mastery. Treat these topics as "studied before, but likely rusty." The user can handle advanced physics language, but explanations should rebuild the conceptual skeleton instead of assuming all definitions, derivations, and standard results are immediately available.

The user has not studied quantum field theory and adjacent advanced field-theory machinery deeply enough to rely on it as prerequisite knowledge. If a topic needs QFT, effective field theory, path integrals, renormalization, gauge theory, or particle-physics conventions, introduce only the minimum needed background first.

## Mathematics Background

The user has studied the mathematics commonly used in physics, but mainly at a computational and applied level. Do not assume comfort with abstract mathematics for its own sake.

When using mathematics, prefer this order:

1. Explain what the object measures or represents physically.
2. Give the simplest useful formula or definition.
3. Show how it is used in a calculation.
4. Only then discuss abstraction, coordinate-free formulations, or proof-level details.

Be careful with topics such as:

- Functional analysis and distributions.
- Differential geometry beyond practical GR use.
- Lie groups, Lie algebras, and representation theory.
- Measure theory and probability foundations.
- Advanced topology.
- Category-like or highly structural language.

When these are needed, bridge from concrete physics examples and calculations.

## Teaching Implications

- Use Chinese by default.
- Keep important English terms next to Chinese names, for example "测地线 (geodesic)".
- Prefer compact derivations with meaning attached to every step.
- State assumptions explicitly.
- Use dimensional analysis, limiting cases, and physical intuition as checkpoints.
- Avoid asking formal exercises before the user has received an explanatory pass.
- After a concept is taught, ask the user to paraphrase, identify a missing step, or choose whether to continue, rather than forcing a quiz immediately.
